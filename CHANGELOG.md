# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

[git-cliff](https://git-cliff.org) writes this file from the commit subjects.
To see the changes that are not in a version, run `git cliff --unreleased`.

## [0.2.0] - 2026-11-26

### Added

- Add the height of a two-line row to the token set
- Show three sidebar directions on the preview page
- Add the motion.indicator token for the turn of the working glyph
- Make the compact two-line row 40 px high
- Show one sidebar with each of its states on the preview page

### Documentation

- Specify the three sidebar directions
- Specify the one sidebar of the desktop client
## [0.1.0] - 2026-11-25

### Added

- Add the token set and the nomux-theme crate
- Add the base themes, the default themes and three palettes
- Add the nomux-theme command, the schema and the preview page

### Documentation

- Describe the themes, the theme file and how to add a theme
